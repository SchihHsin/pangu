# 盘古训推与算子开发体验调研

GitHub Pages 入口位于仓库根目录，自动跳转至完整网页汇报：

`pangu-operator-research-report-v2/index.html`

## 发布 GitHub Pages

在 GitHub 仓库中依次打开 **Settings → Pages**，将 **Build and deployment** 设置为：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/(root)`

保存后，站点地址为：

`https://schihhsin.github.io/pangu/`

Pages 首次发布通常需要几分钟。报告源文件在 `.codex-report-work/build_complete_report.mjs`；更新后重新生成 `pangu-operator-research-report-v2/index.html` 并推送即可。
